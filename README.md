# Сервис бронирования тем исследовательских проектов

Streamlit-приложение для школы:  
ученики бронируют темы и сдают работы, учитель проверяет, скачивает и отправляет на доработку.

## Возможности

### Ученик
- Выбор класса и просмотр свободных тем (сгруппированы по предметам)
- Бронирование темы (одна тема — один ученик)
- Загрузка файла работы (pdf, docx, pptx, zip и др.)
- Просмотр статуса своих работ и комментариев учителя

### Учитель (по паролю)
- Просмотр и скачивание сданных работ
- Смена статуса: «на проверке» → «принято» / «на доработке»
- Добавление комментариев к работам
- **Добавление, редактирование и удаление тем**
- Снятие брони с темы
- Статистика

## Быстрый запуск локально

```bash
git clone <ваш-репозиторий>
cd project_topics_app
pip install -r requirements.txt
streamlit run app.py
```

Откроется в браузере (обычно http://localhost:8501).

## Смена пароля учителя

В файле `app.py` найдите строку:

```python
TEACHER_PASSWORD = "teacher2026"
```

и измените значение на свой пароль.

## Развёртывание на Streamlit Cloud (бесплатно)

1. Создайте репозиторий на GitHub и загрузите все файлы из этой папки
2. Зайдите на [share.streamlit.io](https://share.streamlit.io)
3. Нажмите **New app**
4. Выберите ваш репозиторий
5. В поле **Main file path** укажите: `app.py`
6. Нажмите **Deploy**

После деплоя приложение будет доступно по ссылке вида:  
`https://your-app-name.streamlit.app`

> **Важно:** на Streamlit Cloud файловая система временная.  
> База данных и загруженные файлы могут исчезнуть при перезапуске.  
> Для постоянной работы в школе лучше запускать приложение на школьном компьютере или сервере.

## Как пользоваться

1. Запустите приложение
2. Выберите роль **«Учитель»**
3. Введите пароль
4. Перейдите на вкладку **«Добавить тему»** и добавьте темы по классам
5. Ученики смогут бронировать темы и сдавать работы
